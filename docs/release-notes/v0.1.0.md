## GalvaPlot v0.1.0 · 首个公开版本

把蓝电 `.cex` 或新威 `.ndax` 源文件拖进窗口，一键画出可以直接放进 PPT 和论文的电化学图。不用装 Python，下载即用。

### 下载哪个文件

| 系统 | 文件 | 怎么装 |
|---|---|---|
| **Windows 10/11（推荐）** | `GalvaPlot-0.1.0-Windows-Setup.exe` | 双击安装，一路 Next。默认只装给当前用户，不需要管理员密码 |
| Windows 免安装版 | `GalvaPlot-0.1.0-Windows-x64-portable.zip` | **先完整解压**，再双击文件夹里的 `GalvaPlot.exe` |
| **macOS（Apple 芯片）** | `GalvaPlot-0.1.0-macOS-AppleSilicon.dmg` | 打开后把 GalvaPlot 拖进“应用程序” |

程序没有购买代码签名证书，第一次打开时 Windows 会提示“已保护你的电脑”（点“更多信息 → 仍要运行”），macOS 会提示“无法验证开发者”（到“系统设置 → 隐私与安全性”点“仍要打开”）。详见 [README](../../#下载安装不用装-python)。第一次启动需要 10–30 秒建立字体缓存，以后 1–2 秒。

### 能做什么

- 最多 10 个文件同时对比，蓝电和新威可以混用，也可以直接拖入文件夹
- 四种图：充放电曲线、循环性能（容量、库仑效率、能量效率、保持率、平均电压、ΔV）、电压–时间、dQ/dV
- 曲线名称随意改；`AlCl_{3}` 写下标、`Li^{+}` 写上标；颜色、线型逐条可调
- 容量单位 mAh、mAh/g、mAh/cm² 或相对参考圈 %；图中文字中英文可选；图下方可写测试条件
- 多子图可以用 a/b/c 按钮单独查看、单独导出
- 复制图片直接粘贴到 PPT；保存 PNG / SVG / PDF / TIFF；导出 Excel 数据（可导入 Origin）

### 已知限制

- 蓝电和新威的源文件格式都是逆向解析的，做过内部一致性检查，但**还没有与官方软件导出逐点比对**，重要数据请核对
- 新威只支持 BTS 8.x 写出的 `.ndax`；旧版 `.nda` 暂不支持
- Intel 芯片的 Mac 和 Linux 暂无安装包，可以从源码运行

读不了的文件、画错的图，欢迎在 [Issues](../../issues) 反馈。

**English** — First public release. Drag LAND `.cex` / Neware `.ndax` battery-test files into the window and get publication-style voltage profiles, cycling metrics, voltage–time and dQ/dV plots; copy straight into PowerPoint or export to PNG/SVG/PDF/TIFF and Excel. Downloads: Windows installer (per-user, no admin rights), portable Windows zip, macOS (Apple Silicon) dmg. Both file readers are reverse-engineered and not yet checked against official exports — please verify important numbers.
