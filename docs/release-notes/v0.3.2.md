## GalvaPlot v0.3.2

- 修复：Windows 上的一键更新偶尔会失败（程序关掉了，新版本却没装上，需要手动重新打开旧版）。原因是安装程序启动时 GalvaPlot 还没完全退出。现在安装程序会先等 GalvaPlot 退出，必要时强制关闭，再安装
- 从 0.3.0、0.3.1 一键更新到这个版本也适用，因为等待是由新版本的安装程序完成的

Mac 版和功能与 0.3.1 相同。已装 0.3.0 或 0.3.1 的，点右下角“检查更新”→“立即更新”即可。

| 系统 | 文件 |
|---|---|
| **Windows 10/11（推荐）** | `GalvaPlot-0.3.2-Windows-Setup.exe` |
| Windows 免安装版 | `GalvaPlot-0.3.2-Windows-x64-portable.zip`（先完整解压） |
| **macOS（Apple 芯片）** | `GalvaPlot-0.3.2-macOS-AppleSilicon.dmg` |

---

**English** — Fix for the Windows in-app update: Setup could start while the app was still quitting and then cancel itself, leaving the old version closed and not updated. Setup now waits for GalvaPlot to exit (and force-closes it if needed); this also covers updates started from 0.3.0 / 0.3.1. No other changes.
