## GalvaPlot v0.3.0

### 新功能

- **程序内一键更新**：以后有新版本时，点右下角“检查更新”→“立即更新”。程序会下载新版本，核对 GitHub 公布的校验值后自动安装并重新打开，**不用再到系统设置里放行**
  - 适用于 macOS 装在“应用程序”里的版本，以及 Windows 用安装包装的版本
  - Windows 免安装版仍需手动下载替换
  - 设置和曲线名称会保留

### 修复

- 预览图右键菜单里的“更多设置（坐标范围、字号、图例…）”点了没有反应

### 这一次需要手动安装

0.2.x 及更早的版本还没有这个功能，所以这一次还需要像第一次一样手动下载安装（macOS 第一次打开时，按安装窗口里的说明在系统设置里放行一次）。从 0.3.0 开始，以后的更新都可以在程序里一键完成。

| 系统 | 文件 |
|---|---|
| **Windows 10/11（推荐）** | `GalvaPlot-0.3.0-Windows-Setup.exe` |
| Windows 免安装版 | `GalvaPlot-0.3.0-Windows-x64-portable.zip`（先完整解压） |
| **macOS（Apple 芯片）** | `GalvaPlot-0.3.0-macOS-AppleSilicon.dmg` |

Windows 安装包会直接替换旧版本；macOS 把新的 GalvaPlot 拖进“应用程序”时选“替换”。其他说明见[项目主页的 README](https://github.com/690463389xkc-collab/galvaplot)。

### 说明

- 只有你点了“立即更新”才会下载和安装；检查更新本身只向 GitHub 查询版本号，不上传任何数据
- 程序自己下载的更新没有“来自网络”的标记，所以系统不会再拦；作为替代，程序在安装前核对校验值，下载不完整或被篡改就不安装

---

**English** — New in 0.3.0: in-app update. "Check for updates" → "Update now" downloads the new package, verifies it against the SHA-256 digest GitHub publishes for the release asset, replaces the installed copy and reopens it — no Gatekeeper / SmartScreen approval needed for later updates (macOS app in a writable folder; Windows copies installed with Setup; the portable zip keeps the download link). Fix: "More settings" in the preview's right-click menu did nothing. This version itself still has to be installed manually once.
