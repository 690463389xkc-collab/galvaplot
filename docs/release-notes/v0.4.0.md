## GalvaPlot v0.4.0

### 新功能

- **只画某几圈的电压–时间曲线**：在“电压–时间”里填圈数，如 `2`、`1, 50, 100` 或 `1-5`；留空仍画整个测试
  - “时间起点”可选：**每圈从 0 开始**（各圈叠在一起比较）、**从所选第一圈开始**（按先后连成一条）、**测试开始**
  - 排布新增“**每圈一个子图**”，每圈一张图比较不同电池
  - 一圈包括该圈里的静置段
- **蓝电 .cex 文件自动读入活性物质质量**：在蓝电软件里填过的质量会自动填进“质量 mg”一栏，可直接用 mAh/g 作图；仍可在表格里修改，右键可恢复文件里的值

### 说明

- 蓝电的质量存放位置是根据 143 个本地文件确定的：填了质量、有充放电工步的 76 个文件中，75 个的“设定电流 ÷ 质量”正好等于测试方案的 100 或 500 mA/g。如果你的文件读出的质量和蓝电软件里不一致，欢迎在 Issues 里反馈
- 已装 0.3.0 及以后版本的，点右下角“检查更新”→“立即更新”即可

**English** — New in 0.4.0: voltage vs time for chosen cycles (a cycle field on the 电压–时间 tab; time axis per cycle from zero, joined from the first chosen cycle, or test time; new "one panel per cycle" arrangement). The active-material mass entered in LAND is now read from `.cex` files (header, float32 in g) and fills the mass column, like Neware files. Update from 0.3.x with "Check for updates" → "Update now".
