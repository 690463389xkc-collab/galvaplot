## GalvaPlot v0.2.1

功能与 0.2.0 相同，只改进了 macOS 安装体验。

### 改进

- **macOS 安装窗口里加了第一次打开的说明**：程序没有苹果开发者签名，第一次打开时系统会提示“无法验证”，提示框里最显眼的蓝色按钮是“移到废纸篓”，点了程序就被删掉了。现在打开 dmg 就能看到三步说明：
  1. 提示框里点「完成 Done」，**不要点「移到废纸篓 Move to Trash」**
  2. 打开「系统设置 → 隐私与安全性」，在“安全性”一栏点「仍要打开」，输入开机密码
  3. 再双击 GalvaPlot 即可，以后不会再提示
- README 里也加了同样的图文说明

已经装好 0.2.0 并能正常打开的，不更新也没关系。

### 下载

| 系统 | 文件 |
|---|---|
| **Windows 10/11（推荐）** | `GalvaPlot-0.2.1-Windows-Setup.exe` |
| Windows 免安装版 | `GalvaPlot-0.2.1-Windows-x64-portable.zip`（先完整解压） |
| **macOS（Apple 芯片）** | `GalvaPlot-0.2.1-macOS-AppleSilicon.dmg` |

像第一次一样安装即可：Windows 安装包会直接替换旧版本；macOS 把新的 GalvaPlot 拖进“应用程序”时选“替换”。原来的设置会保留。其他说明见[项目主页的 README](https://github.com/690463389xkc-collab/galvaplot)。

---

**English** — Same features as 0.2.0. The macOS disk image now shows the first-launch steps for the unsigned app (press "Done", not "Move to Trash"; then System Settings → Privacy & Security → Open Anyway). Users with a working 0.2.0 do not need to update.
