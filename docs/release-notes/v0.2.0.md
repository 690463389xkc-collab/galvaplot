## GalvaPlot v0.2.0

### 新功能

- **所有圈+所有电池**：充放电曲线和 dQ/dV 新增这种排布，所有电池的所有选定圈画在一张图里，颜色区分电池，线型区分圈数（超过 4 圈时用颜色深浅区分）
- **右键菜单**：在预览图的某个子图上点右键，可以单独复制它的数据（直接粘贴到 Excel / Origin）、复制或保存这个子图、只显示或隐藏它
- **新威文件自动读取活性物质质量**：在 BTS 里设置过的质量会自动填进“质量 mg”一栏，可以修改；右键可以恢复文件里的值
- **检查更新**：窗口右下角，有新版本时给出下载链接

### 怎么更新

下载下面对应系统的文件，像第一次一样安装即可：Windows 安装包会直接替换旧版本；macOS 把新的 GalvaPlot 拖进“应用程序”时选“替换”。原来的设置、曲线名称和质量都会保留。以后可以直接点程序右下角的“检查更新”。

| 系统 | 文件 |
|---|---|
| **Windows 10/11（推荐）** | `GalvaPlot-0.2.0-Windows-Setup.exe` |
| Windows 免安装版 | `GalvaPlot-0.2.0-Windows-x64-portable.zip`（先完整解压） |
| **macOS（Apple 芯片）** | `GalvaPlot-0.2.0-macOS-AppleSilicon.dmg` |

第一次打开的系统提示和其他说明见[项目主页的 README](https://github.com/690463389xkc-collab/galvaplot)。

### 说明

- 检查更新只向 GitHub 查询最新版本号，不上传任何数据或文件；默认每天启动时最多自动检查一次，可以在检查更新的窗口里关掉
- 新威质量读自工步文件里的 `SCQ` 项（按 µg 换算）。在 15 个设置了质量的参考文件上，按这个单位换算后程序设定的电流都正好是 100 或 200 mA/g；如有不符请在表格里改，并欢迎反馈
- 蓝电和新威的读取仍然是逆向得到的，还没有与官方软件导出逐点比对，重要数据请核对

**English** — New in 0.2.0: "all cycles + all cells" in one panel for voltage profiles and dQ/dV; a right-click menu on the preview to copy one sub-plot's data (pastes into Excel/Origin) or save it on its own; the active mass stored in Neware `.ndax` files is read automatically; "check for updates" in the status bar (GitHub Releases API only, at most once a day, can be switched off). Install over the old version; settings are kept.
