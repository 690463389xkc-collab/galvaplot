## GalvaPlot v0.3.1

- 新增：保存图片可以选 **EPS** 格式（“保存图片…”和右键“保存此子图…”）
- 修复：在 Mac 上导出的**带中文的 PDF**，用“预览”以外的软件打开（如 Acrobat、Illustrator、LaTeX）时中文可能缺失或乱码。这个问题从 0.1.0 就存在，建议用新版重新导出需要放进论文的 PDF
- 修复：带中文的 EPS 打不开
- 改进：Windows 一键更新时会留下安装日志，出问题方便排查

已经装了 0.3.0 的，点右下角“检查更新”→“立即更新”即可，不用再到系统设置里放行。

### 说明

Mac 上的中文字体（苹方）不能以普通方式嵌入 PDF/EPS，所以带中文的图现在改用另一种嵌入方式（Type 3）：用 Ghostscript 和“预览”核对过都能正确显示，但在 Illustrator 里中文可能不能直接当文字编辑。纯英文的图不受影响，文字仍可编辑。Windows 上的中文字体（雅黑）不受影响。

| 系统 | 文件 |
|---|---|
| **Windows 10/11（推荐）** | `GalvaPlot-0.3.1-Windows-Setup.exe` |
| Windows 免安装版 | `GalvaPlot-0.3.1-Windows-x64-portable.zip`（先完整解压） |
| **macOS（Apple 芯片）** | `GalvaPlot-0.3.1-macOS-AppleSilicon.dmg` |

---

**English** — New: save figures as EPS. Fix: on macOS, PDFs (since 0.1.0) and EPS files containing Chinese text embedded the Chinese font (PingFang, CFF outlines) as TrueType, which only macOS Preview displays correctly; such figures now embed fonts as Type 3. Windows in-app updates now leave a Setup log. Users of 0.3.0 can update from inside the app.
